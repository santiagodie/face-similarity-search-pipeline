Face Similarity Search

Static demo with precomputed embeddings

This page searches a small index of 115 face crops: 23 synthetic faces, each in five versions (original, tighter crop, slight rotation, brighter, mirrored). None of them is a real person. The faces come from SFHQ part 3 by David Beniaguev, released under CC0.

The 128-d FaceNet embeddings were computed with the pipeline in this repository: dlib detection, a 20% margin, a 160×160 crop and FaceNet through DeepFace. When you pick a face, your browser compares its embedding with all 115 using an exact linear search (Euclidean distance). The VP-tree index from the original pipeline is used in the notebook. Distances up to 9.655, the F1-optimal threshold from the evaluation notebook, count as a match.
